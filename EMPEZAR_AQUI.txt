⚡ INICIO RÁPIDO (45 minutos)

PASO 1: Subir a GitHub (5 min)
→ GitHub Desktop o github.com/new
→ Crear repo "tucanbot" (privado)
→ Subir carpeta C:\Users\mario\tucanbot

PASO 2: Easypanel - Crear servicio (10 min)
→ Abrir Easypanel
→ Create Service → App → "tucanbot"
→ Conectar GitHub
→ Build: npm install
→ Start: npm start
→ Port: 3000

PASO 3: Variables de entorno (5 min)
→ Copiar las 7 variables de .env
→ Agregar en Easypanel Environment
→ IMPORTANTE: Completar EVOLUTION_API_URL y EVOLUTION_API_KEY

PASO 4: Deploy (2 min)
→ Click "Deploy"
→ Esperar logs
→ Copiar URL de TucánBot

PASO 5: WhatsApp (5 min)
→ En Evolution, crear instancia "tucanbot-pizzeria"
→ Escanear QR con WhatsApp

PASO 6: Webhook (3 min)
→ Configurar webhook en Evolution
→ URL: https://tucanbot.tudominio.com/webhook
→ Header: x-api-key

PASO 7: Probar (2 min)
→ Enviar "hola" por WhatsApp
→ Debe responder con el menú
