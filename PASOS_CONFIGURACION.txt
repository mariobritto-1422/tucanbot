📱 PRÓXIMO PASO: CONECTAR EVOLUTION API

   Cuando tengas Evolution API configurada:

   1. Editar .env:
      EVOLUTION_API_URL=https://tu-evolution-api.com
      EVOLUTION_API_KEY=tu_api_key

   2. Crear instancia en Evolution API con nombre: tucanbot-pizzeria

   3. Configurar webhook apuntando a tu TucánBot

   4. ¡Listo! Empezarás a recibir mensajes de WhatsApp real
